One Word, First Thought — a program that writes exactly one word, **apricity**, and nothing else. Apricity is the warmth of the winter sun on the skin: a feeling everyone has felt on a cold, bright day, but almost no one has a word for. It was chosen as the first word that came to mind — surprising rather than safe, vivid and specific, with a warm, bright sound that rewards a second look. The program writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), deterministically, with zero network requests.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
